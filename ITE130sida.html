SAMARBETE OCH VERSIONSHANTERING

Git och GitHub

Git är ett versionshanteringssystem som håller reda på ändringar i ett projekt. Med Git kan du spara arbetet i så kallade commits, se vad som har ändrats och gå tillbaka till en tidigare version om något blir fel. Du kan också skapa separata grenar (branches) för att prova nya idéer utan att påverka huvudversionen.

GitHub är en webbtjänst där Git-projekt kan lagras och delas. Där kan flera personer samarbeta genom att föreslå ändringar, granska kod och diskutera uppgifter. GitHub gör alltså det enklare att samarbeta kring projekt på nätet.

VERKTYG FÖR WEBBUTVECKLING

Bootstrap

Bootstrap är ett front-end-ramverk som hjälper dig att bygga webbsidor som fungerar på både mobil och dator. Det innehåller ett responsivt rutnät med rader och kolumner som anpassar layouten efter skärmens storlek.

Ramverket innehåller också färdiga CSS-klasser och komponenter, till exempel navbarer, kort och knappar. Det gör det enklare att skapa en enhetlig design och komma igång med sidans utseende. Bootstrap kan anpassas med egen CSS, som på den här sidan.
